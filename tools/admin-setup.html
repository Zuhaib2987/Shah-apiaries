Admin setup

Creates the two secrets your Shah Apiaries dashboard needs.

Passwords never leave this phone. They're scrambled right here in your browser, and only the scrambled version is shown below.

1. Choose two logins

2. Copy into Cloudflare

Worker shah-apiaries → Settings → Variables and Secrets → Add → type Secret.

Name: SESSION_SECRET
Name: ADMIN_USERS

Copied

3. Then

  1. Save both secrets. Cloudflare redeploys by itself.
  2. Open your shop link and add /admin at the end.
  3. Log in with the username and password you chose.

Write the passwords down somewhere safe. They can't be recovered, only replaced by running this page again.
